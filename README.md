# Grup1_AuthProject - Authentication Module

Bilgisayar Mühendisliğinde Proje Yönetimi laboratuvar uygulaması kapsamında geliştirilen **Jira & GitHub Entegrasyonu ile Kanban** projesidir.

## Modül Kapsamı
- **Frontend:** Kayıt (`register.html`), Giriş (`login.html`) ve Şifre Sıfırlama (`reset-password.html`) ekranları
- **Backend:** Register, Login ve Şifre Sıfırlama REST API uç noktaları
- **Testler:** Uçtan uca modül entegrasyon testleri (`node --test`)

## Çalıştırma
```bash
npm start
```
Testleri çalıştırmak için:
```bash
npm test
```
